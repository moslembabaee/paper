# Brag Plan: Paper

## What is this app?
Paper is an open-source, self-hosted, code-bridged infinite canvas design platform inspired by Paper.design, developed 100% autonomously by the Tri-Agent Orchestra (Claude Code, OpenAI Codex, and Google Antigravity).

## The angle
Autonomous AI agents built a vector canvas design tool so good you'd think a 20-person design systems team built it over two years. 60 FPS vector canvas, real-time shaders, Dev Mode code generation, and zero subscription costs.

## Hook (first 2-3 seconds)
A sleek, mysterious terminal/studio interface boots up: "What if 3 autonomous AI agents built a Figma competitor while you were asleep?" Claude Code ✕ OpenAI Codex ✕ Google Antigravity badges lock in with high-voltage accent pulses.

## Key moments (the middle)
- **The Infinite Canvas**: Dark studio aesthetic (`#0c0c0e`), 120px precision engineering grid, pixel rulers, 60 FPS hardware acceleration zooming across artboards and vector paths.
- **Real-Time Shaders**: Official `@paper-design/shaders-react` engine running live Mesh Gradients, CMYK Halftone, and Gooey metaballs directly inside the artboard.
- **Dev Mode Code Bridge**: One-click toggle inspecting CSS box model, generating clean copyable React + Tailwind production code, powered by a native Model Context Protocol (MCP) server.

## Outro / punchline
"100% AUTONOMOUS. 0% HUMAN COMMITS."
One command to self-host: `docker compose up`. Open-source on GitHub.

## User flow worth showing
1. Canvas navigation & precision grid zoom (entry)
2. Vector manipulation with real-time reactive shaders (action)
3. One-click Dev Mode inspect to copy production React code (result)
